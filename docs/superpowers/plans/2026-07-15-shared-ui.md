# Shared UI Design System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land a shadcn-style `shared_ui` package (`Tp*` components + `TpTheme` tokens) as a git submodule and migrate TeamPilot’s generic `App*` primitives onto it with no compatibility shims.

**Architecture:** Rewrite the existing `hhoao/shared_ui` repo into a pure Flutter UI library (no bloc/l10n/routing). `TpTheme` (InheritedWidget) holds tokens + component themes; `client` keeps color presets, font loading, and `MaterialApp` assembly, then wraps the tree with `TpTheme`. Migrated widgets move from `client/lib/widgets/` into the package and rename `App*` → `Tp*`.

**Tech Stack:** Flutter/Dart, Material 3, `toggle_switch` (for `TpSegmentedControl` only), git submodule at `client/packages/shared_ui`.

**Spec:** `docs/superpowers/specs/2026-07-15-shared-ui-design.md`

**Important precondition:** GitHub `hhoao/shared_ui` already exists with an older `App*` + appearance/chrome/l10n surface used by huji. This plan **breaking-rewrites** that package to the approved Tp design. Huji updates are out of scope for TeamPilot; coordinate separately if needed.

### Porting rule (all migrate tasks)

When moving a widget into `shared_ui`:

1. **Forbidden imports:** anything under `package:teampilot/...`.
2. Replace `cs.workspaceCard` / `workspaceSubtleSurface` / other `workspace_surface_layers` colors with Material 3 `ColorScheme` roles (`surface`, `surfaceContainer`, `surfaceContainerHighest`, `outlineVariant`, …).
3. Replace `AppTextStyles.*` with `TpTypography` / `Theme.of(context).textTheme` roles owned by the package.
4. Replace `context.appSpacing` / `context.appIconSizes` with `context.tpSpacing` / `context.tpIconSizes`.

### Stay in `client` (do not move)

class TpThemeData {
  const TpThemeData({
    required this.spacing,
    required this.iconSizes,
    required this.typography,
    required this.control,
    // component themes added as components land; nullable with defaults OK
  });

  factory TpThemeData.fromColorScheme(
    ColorScheme scheme, {
    required double scale,
  }) { /* build tokens from scale; ignore unused scheme until component themes need it */ }

  final TpSpacing spacing;
  final TpIconSizes iconSizes;
  final TpTypography typography;
  final TpControlMetrics control;
}

class TpTheme extends InheritedWidget {
  const TpTheme({super.key, required this.data, required super.child});
  final TpThemeData data;
  static TpThemeData of(BuildContext context) { /* … */ }
  static TpThemeData? maybeOf(BuildContext context) { /* … */ }
  @override
  bool updateShouldNotify(TpTheme old) => data != old.data;
}

extension TpThemeContext on BuildContext {
  TpThemeData get tpTheme => TpTheme.of(this);
  TpSpacing get tpSpacing => tpTheme.spacing;
  TpIconSizes get tpIconSizes => tpTheme.iconSizes;
