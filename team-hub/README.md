# Team Hub registry

Public team templates for TeamPilot live in this subdirectory of
[`hhoao/teampilot`](https://github.com/hhoao/teampilot).

```
team-hub/
  index.json              # { "teams": [ { "slug": "…" }, … ] }
  teams/<slug>/team.json  # DiscoverableTeam JSON
```

Catalog keys are stamped as `hhoao/teampilot/team-hub/<slug>`.
